🔔 KHỐI CÒI: TRANSISTOR S8050 NPN (VỎ TO-92)

• Chân 1 (E - Trái): Nối thẳng vào GND của Pi.
• Chân 2 (B - Giữa): Nối qua Điện trở 1 kΩ ➔ Chân Pin 18 (GPIO 24).
• Chân 3 (C - Phải): Nối vào Cực âm (-) của Còi Buzzer 5V.
• Cực dương (+) Còi: Nối lên 5V. Mắc song song Diode 1N4148 (vạch trắng vào +5V).

QUY TRÌNH HÀN MẠCH & LẮP RÁP AN TOÀN 5 GIAI ĐOẠN (ALTIUM EDA STANDARD)

Thực hiện tuần tự từng giai đoạn, đo kiểm tra điện áp trước khi cắm Pi để chống cháy vi xử lý

GIAI ĐOẠN 1 ⚡ NGUỒN
Chỉnh Áp Buck 5.10V

1. Nối Pin 2S qua công tắc vào IN+ và IN- của mạch Buck XL4015.
2. Chưa cắm Pi! Dùng đồng hồ VOM đo OUT+ và OUT-, vặn biến trở tinh chỉnh về đúng 5.10V.
3. Khóa vít biến trở bằng sơn móng tay / keo nến chống rung lắc khi đi xe.

GIAI ĐOẠN 2 📳 HAPTIC
Hàn Khối ULN2003A

1. Hàn chân 8 (GND) về Mass chung.
2. Hàn chân 9 (COM) lên đường 5V.
3. Hàn cực (+) 4 motor rung vào 5V.
4. Hàn cực (-) 4 motor vào OUT1..OUT4.
5. Hàn dây tín hiệu từ IN1..IN4 về các hàng chân header cắm vào Pin 11, 13, 15, 16 của Pi.

GIAI ĐOẠN 3 🔔 CÒI & SOS
Hàn S8050 & Nút SOS

1. S8050: Emitter (1) về GND, Collector (3) vào (-) Còi, Base (2) nối tiếp qua trở 1kΩ về Pin 18 (GPIO 24).
2. Hàn Diode 1N4148 ngược chiều song song còi.
3. Nút SOS: 1 chân vào Pin 22 (GPIO 25), chân kia vào GND (Pin 20), hàn tụ 100nF song song 2 chân.

GIAI ĐOẠN 4 🛰️ CẢM BIẾN
Hàn I2C & UART

1. Laser VL53L0X: Hàn SDA vào Pin 3, SCL vào Pin 5, VIN vào Pin 1 (3.3V), GND vào Pin 9.
2. GPS NEO-6M: Hàn TXD vào Pin 10 (RXD Pi), RXD vào Pin 8 (TXD Pi), VCC vào 3.3V/5V, GND vào Pin 6.
3. Dùng dây bọc chống nhiễu cho đường I2C/UART nếu dây dài hơn 15cm.

GIAI ĐOẠN 5 📷 CỤM 3 CAM
Gá Lắp Nón & Chạy Thử

1. Gá cụm 3 camera trên đỉnh nón lệch nhau 120° bằng khung in 3D.
2. Luồn cáp USB vào Hub 3.0, cắm Hub vào cổng USB 3.0 màu xanh dương.
3. Gắn 4 motor rung vào 4 điểm đệm xốp nón (Trán, Phải, Gáy, Trái).
4. Bật công tắc nguồn, mở terminal chạy script kiểm thử `test_hardware_pi.py`.

Script tự động test tuần tự: 4 Motor rung định hướng, Còi buzzer S8050, Nút bấm SOS, Cảm biến Laser VL53L0X, GPS NEO-6M và 3 Camera 360°

#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
DỰ ÁN: MŨ BẢO HIỂM THÔNG MINH 360° AI (SMART HELMET)
FILE TEST TOÀN DIỆN PHẦN CỨNG: 4 MOTOR RUNG + CÒI S8050 + NÚT SOS + VL53L0X + GPS + 3 CAM 120°
"""
import time
import sys
import RPi.GPIO as GPIO

# ================= CẤU HÌNH CHÂN GPIO =================
PIN_MOTOR_FRONT = 17   # Pin 11: Motor Trước (Trán)
PIN_MOTOR_RIGHT = 27   # Pin 13: Motor Phải (Thái dương phải)
PIN_MOTOR_REAR  = 22   # Pin 15: Motor Sau (Gáy)
PIN_MOTOR_LEFT  = 23   # Pin 16: Motor Trái (Thái dương trái)
PIN_BUZZER      = 24   # Pin 18: Còi Buzzer kích S8050
PIN_SOS         = 25   # Pin 22: Nút báo động khẩn cấp SOS

def test_haptic_motors():
    print("
[1/5] TEST 4 MOTOR RUNG HAPTIC (ULN2003A)...")
    motors = [
        ("TRƯỚC (Trán)", PIN_MOTOR_FRONT),
        ("PHẢI (Thái dương phải)", PIN_MOTOR_RIGHT),
        ("SAU (Gáy)", PIN_MOTOR_REAR),
        ("TRÁI (Thái dương trái)", PIN_MOTOR_LEFT)
    ]
    for name, pin in motors:
        print(f"  -> Rung motor {name} (GPIO {pin})...")
        GPIO.output(pin, GPIO.HIGH)
        time.sleep(0.35)
        GPIO.output(pin, GPIO.LOW)
        time.sleep(0.15)
    print("  ✓ Đã hoàn thành vòng rung 360°!")

def test_buzzer():
    print("
[2/5] TEST CÒI BÁO ĐỘNG S8050 NPN (GPIO 24)...")
    for i in range(3):
        GPIO.output(PIN_BUZZER, GPIO.HIGH)
        time.sleep(0.12)
        GPIO.output(PIN_BUZZER, GPIO.LOW)
        time.sleep(0.08)
    print("  ✓ Đã phát 3 tiếng bíp thành công!")

def test_sos_button():
    print("
[3/5] TEST NÚT BẤM SOS (GPIO 25)... (Nhấn nút trên nón trong 5 giây)")
    start = time.time()
    pressed = False
    while time.time() - start < 5.0:
        if GPIO.input(PIN_SOS) == GPIO.LOW:  # Kéo lên nội, nhấn nút mức 0
            pressed = True
            print("  🚨 ĐÃ PHÁT HIỆN NHẤN NÚT SOS KHẨN CẤP!")
            # Kêu còi và rung 4 motor phản hồi
            GPIO.output(PIN_BUZZER, GPIO.HIGH)
            time.sleep(0.3)
            GPIO.output(PIN_BUZZER, GPIO.LOW)
            break
        time.sleep(0.05)
    if not pressed:
        print("  - Hết 5s: Chưa thấy nhấn nút SOS (hoặc chưa lắp).")

def test_i2c_vl53l0x():
    print("
[4/5] TEST CẢM BIẾN LASER ToF VL53L0X (I2C)...")
    try:
        import board
        import busio
        import adafruit_vl53l0x
        i2c = busio.I2C(board.SCL, board.SDA)
        vl53 = adafruit_vl53l0x.VL53L0X(i2c)
        print(f"  ✓ Đọc khoảng cách laser: {vl53.range} mm ({vl53.range / 10.0:.1f} cm)")
    except Exception as e:
        print(f"  - VL53L0X chưa kết nối hoặc thiếu thư viện: {e}")

def test_cameras():
    print("
[5/5] TEST CỤM 3 CAMERA USB 120° TAM GIÁC (360° FOV)...")
    import cv2
    cam_indices = [0, 2, 4]  # Mặc định USB camera 1, 2, 3
    for idx in cam_indices:
        cap = cv2.VideoCapture(idx)
        if cap.isOpened():
            ret, frame = cap.read()
            if ret:
                h, w, _ = frame.shape
                print(f"  ✓ Camera /dev/video{idx}: Khởi tạo OK, Frame: {w}x{h}")
            else:
                print(f"  ! Camera /dev/video{idx}: Mở được nhưng không bắt được frame.")
            cap.release()
        else:
            print(f"  - Camera /dev/video{idx}: Không mở được.")

def main():
    print("=" * 65)
    print("  BỘ KIỂM THỬ PHẦN CỨNG MŨ BẢO HIỂM THÔNG MINH 360° - RASPBERRY PI 4")
    print("=" * 65)
    
    GPIO.setmode(GPIO.BCM)
    GPIO.setwarnings(False)
    
    # Cấu hình OUTPUT
    for pin in [PIN_MOTOR_FRONT, PIN_MOTOR_RIGHT, PIN_MOTOR_REAR, PIN_MOTOR_LEFT, PIN_BUZZER]:
        GPIO.setup(pin, GPIO.OUT, initial=GPIO.LOW)
        
    # Cấu hình INPUT PULL-UP cho nút SOS
    GPIO.setup(PIN_SOS, GPIO.IN, pull_up_down=GPIO.PUD_UP)
    
    try:
        test_haptic_motors()
        test_buzzer()
        test_sos_button()
        test_i2c_vl53l0x()
        test_cameras()
        print("
" + "=" * 65)
        print("  ✓ TẤT CẢ NGOẠI VI ĐÃ ĐƯỢC KIỂM TRA XONG! HỆ THỐNG SẴN SÀNG.")
        print("=" * 65)
    finally:
        GPIO.cleanup()

if __name__ == "__main__":
    main()
